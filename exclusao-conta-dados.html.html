Solicitação de Exclusão de Conta e Dados

FortSmart Agro

⚠️ Informação Importante

O FortSmart Agro armazena seus dados localmente no seu dispositivo usando SQLite. Isso significa que seus dados permanecem no seu smartphone ou tablet e não são enviados para nossos servidores por padrão.

1. Como Funciona a Exclusão de Dados

1.1. Dados Armazenados Localmente

Como o aplicativo FortSmart Agro funciona principalmente offline e armazena dados localmente no seu dispositivo, a exclusão pode ser feita de duas formas:

📱 Opção 1: Desinstalar o Aplicativo (Mais Simples)

  1. Acesse as configurações do seu dispositivo Android
  2. Vá em "Aplicativos" ou "Apps"
  3. Encontre "FortSmart Agro" na lista
  4. Toque em "Desinstalar"
  5. Confirme a desinstalação

Resultado: Todos os dados do aplicativo, incluindo banco de dados SQLite, serão excluídos permanentemente do seu dispositivo.

📧 Opção 2: Solicitar Exclusão por Email

Se você optou por sincronizar dados (caso essa funcionalidade esteja disponível) ou se deseja garantir a exclusão completa, você pode solicitar por email:

  1. Envie um email para: fortsmart.01@gmail.com
  2. No assunto, escreva: "Solicitação de Exclusão de Dados - FortSmart Agro"
  3. No corpo do email, informe:
    • Seu nome completo
    • Endereço de email usado no aplicativo (se houver)
    • Número de telefone associado (se houver)
    • Confirmação de que deseja excluir todos os dados
  4. Aguarde nossa confirmação (até 7 dias úteis)

2. Dados que Serão Excluídos

Ao desinstalar o aplicativo ou solicitar exclusão, os seguintes dados serão excluídos permanentemente:

2.1. Dados de Conta

  • Informações de perfil do usuário
  • Credenciais de login (se houver)
  • Preferências do aplicativo

2.2. Dados Agrícolas

  • Informações de fazendas e propriedades
  • Dados de talhões (áreas, culturas, safras)
  • Registros de plantio
  • Dados de monitoramento
  • Registros de aplicações
  • Informações de colheita
  • Análises de solo
  • Fotos e imagens capturadas
  • Relatórios e prescrições
  • Todos os outros dados técnicos armazenados

2.3. Banco de Dados Completo

  • Todo o banco de dados SQLite
  • Backups locais (se existirem)
  • Cache e arquivos temporários

3. Dados que NÃO Serão Excluídos (se aplicável)

Importante: Como o FortSmart Agro armazena dados principalmente no seu dispositivo, não mantemos cópias dos seus dados em nossos servidores (exceto se você optou explicitamente por sincronização).

Se você fez backups manuais (exportações) e salvou em outros locais (como Google Drive, Dropbox, ou no seu computador), esses backups não serão excluídos automaticamente e você precisará excluí-los manualmente se desejar.

4. Período de Processamento

  • Desinstalação do app: Exclusão imediata (todos os dados são removidos do dispositivo no momento da desinstalação)
  • Solicitação por email: Processaremos sua solicitação em até 7 dias úteis e enviaremos confirmação por email

5. Efeitos da Exclusão

⚠️ ATENÇÃO: A exclusão de dados é PERMANENTE e IRREVERSÍVEL.

Após a exclusão, você não poderá recuperar:

  • Histórico de plantios
  • Dados de monitoramento
  • Relatórios e análises
  • Fotos e imagens
  • Qualquer outro dado do aplicativo

Recomendação: Antes de excluir, faça um backup dos seus dados usando a funcionalidade de exportação do aplicativo (se disponível).

6. Contato

Para solicitar a exclusão de conta e dados, entre em contato:

Email: fortsmart.01@gmail.com

Assunto do email: "Solicitação de Exclusão de Dados - FortSmart Agro"

Tempo de resposta: Até 7 dias úteis

7. Lei Aplicável

Esta política de exclusão está em conformidade com a Lei Geral de Proteção de Dados (LGPD - Lei 13.709/2018) do Brasil, que garante o direito à exclusão de dados pessoais ("direito ao esquecimento").
