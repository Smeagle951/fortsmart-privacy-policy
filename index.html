Política de Privacidade

FortSmart Agro

Última atualização: Janeiro 2026

1. INFORMAÇÕES GERAIS

O FortSmart Agro ("nós", "nosso", "aplicativo") respeita sua privacidade e está comprometido em proteger seus dados pessoais. Esta política explica como coletamos, usamos e protegemos suas informações.

2. DADOS COLETADOS

2.1. Dados Fornecidos pelo Usuário

Coletamos os seguintes dados quando você usa o aplicativo:

  • Informações de Conta: Nome, email, senha (criptografada)
  • Dados de Fazendas: Nome, localização, informações de propriedades rurais
  • Dados de Talhões: Informações geográficas, área, cultura, safras
  • Dados Técnicos: Registros de plantio, monitoramento, aplicações, custos
  • Fotos: Imagens capturadas para documentação agronômica

2.2. Dados Coletados Automaticamente

  • Localização GPS: Para georreferenciamento de registros (apenas quando você autoriza)
  • Dados de Uso: Informações sobre como você usa o aplicativo
  • Dados do Dispositivo: Modelo, versão do sistema operacional

3. COMO USAMOS SEUS DADOS

Usamos seus dados para:

  • Fornecer e melhorar nossos serviços
  • Processar e armazenar suas informações agrícolas
  • Gerar relatórios e análises
  • Sincronizar dados entre dispositivos
  • Enviar atualizações e notificações (se autorizado)
  • Prestar suporte técnico

4. ARMAZENAMENTO DE DADOS

4.1. Armazenamento Local

Seus dados são armazenados localmente no seu dispositivo usando SQLite. Isso significa:

  • Seus dados permanecem no seu dispositivo
  • O aplicativo funciona 100% offline
  • Você tem controle total sobre seus dados

4.2. Sincronização (Opcional)

Se você optar por sincronizar seus dados:

  • Dados são armazenados de forma segura em servidores
  • Conexões são criptografadas (HTTPS)
  • Dados são protegidos com segurança de nível empresarial

5. COMPARTILHAMENTO DE DADOS

Não vendemos, alugamos ou compartilhamos seus dados pessoais com terceiros, exceto:

  • Quando você autoriza explicitamente (ex: compartilhar relatórios)
  • Para cumprir obrigações legais
  • Para proteger nossos direitos e segurança

6. SEGURANÇA

Implementamos medidas de segurança para proteger seus dados:

  • Criptografia de senhas
  • Conexões HTTPS para sincronização
  • Armazenamento local seguro
  • Acesso restrito aos dados

7. SEUS DIREITOS

Você tem o direito de:

  • Acessar seus dados pessoais
  • Corrigir dados incorretos
  • Solicitar exclusão de dados
  • Exportar seus dados
  • Revogar consentimento

8. COOKIES E TECNOLOGIAS SIMILARES

O aplicativo pode usar tecnologias similares para:

  • Melhorar a experiência do usuário
  • Analisar uso do aplicativo
  • Personalizar conteúdo

9. MENORES DE IDADE

O aplicativo não é destinado a menores de 18 anos. Não coletamos intencionalmente dados de menores.

10. MUDANÇAS NESTA POLÍTICA

Podemos atualizar esta política periodicamente. Notificaremos sobre mudanças significativas através do aplicativo ou por email.

Esta política é regida pelas leis brasileiras, especialmente a Lei Geral de Proteção de Dados (LGPD - Lei 13.709/2018).

Ao usar o FortSmart Agro, você concorda com esta Política de Privacidade.
